Backup & Restore

A backup is one file: the database plus every EPUB, cached image and cover. The same file is how you move the whole installation to a new machine -- restoring it there brings your feeds, categories, articles and read state across, not just settings.

It does not include .env -- credentials stay on this machine and must be set up separately on a new one. It does include anything stored in the database, such as a fediverse access token on a Threads feed, so handle a backup file the way you would handle that token.
